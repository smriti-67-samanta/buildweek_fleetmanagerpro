## Fleet Management System
A modern web application for efficient logistics and transportation management, built with React and Firebase.

## Overview
FleetManagerPro helps businesses manage their vehicle fleet with features for tracking, maintenance scheduling, driver management, and operational analytics.

## Features
Vehicle Tracking - Add and manage vehicle details with simulated location tracking

Maintenance Scheduling - Schedule and track routine maintenance with calendar reminders

Driver Management - Manage driver profiles and simulated performance history

Fuel Management - Track fuel consumption and identify inefficiencies

## Tech Stack
 React,Firebase,Netlify
